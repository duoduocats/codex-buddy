# CodexBuddy Beta

[正式版说明 / Stable guide](../README.md) · [English](#english)

## 中文

当前测试版为 **2.5.2-beta.1**：[下载 Beta](https://github.com/duoduocats/codex-buddy/releases/tag/v2.5.2-beta.1)。正式版仍为 **2.5.1**，见 [README](../README.md)。

本版统一 CodexBuddy 显示名称，更新主面板左上角的猫头与双行字标，还原设计稿字形并做垂直居中；用量预测移除“使用 Tibo 估计”，手动额外重置模拟保持可用。应用图标与其他页面布局保持不变。

### 安装与更新

- Apple Silicon、macOS 13+；下载 arm64 DMG，按[安装指南](../README.md#下载与首次安装)操作。
- 本次 Beta **不发送后台更新提醒，不自动安装**。可自行下载；如需在应用内手动检查 Beta，在 **通用 → 更新** 开启“接收 Beta 更新”。
- Beta 接收默认关闭。关闭后不再接收新的 Beta，也不会自动降级已安装的测试版。
- 当前正式版的功能与使用说明保留在 README；本测试版变更见[发布说明](../releases/v2.5.2-beta.1.md)。

历史版本：[2.5.0-beta.4](https://github.com/duoduocats/codex-buddy/releases/tag/v2.5.0-beta.4) · [Beta 4 历史使用说明](https://github.com/duoduocats/codex-buddy/blob/v2.5.0-beta.4/docs/BETA.md)。

## English

The current preview is **2.5.2-beta.1**: [Download Beta](https://github.com/duoduocats/codex-buddy/releases/tag/v2.5.2-beta.1). Stable remains **2.5.1**; see [README.en.md](../README.en.md).

This Beta unifies the displayed CodexBuddy name, adds the main-window cat and two-line wordmark, restores the approved letterforms and centers the visible artwork. Usage forecast drops “Use Tibo estimate” while retaining manual extra-reset scenarios. The application icon and other page layouts are unchanged.

### Install and update

- Apple Silicon, macOS 13+. Download the arm64 DMG and follow the [installation guide](../README.en.md#download-and-install).
- This Beta **does not show background update prompts or install automatically**. Download it manually, or enable **Receive Beta updates** under **General → Updates** and check manually.
- Beta reception is off by default. Disabling it stops new Beta updates without automatically downgrading an installed preview.
- The README continues to describe the stable release. See the [release notes](../releases/v2.5.2-beta.1.md) for this Beta.
