# CodexBuddy v2.5.2-beta.1

## 更新内容

- 应用显示名称统一为 CodexBuddy。
- 主面板使用左猫头、右侧双行字标的新品牌区，四个字母内圆填蓝，并适配浅色与深色模式。
- 字标按设计稿轮廓还原，猫头与完整字标按可见范围垂直居中。
- 用量预测移除“使用 Tibo 估计”入口，保留手动额外重置模拟。

## 更新方式

本次 Beta 不发送后台更新提醒，也不自动安装。需要体验时，请自行下载，或开启 Beta 接收后手动检查更新。正式版 Latest 保持 2.5.1。

## What’s new

- Unify the displayed application name as CodexBuddy.
- Add the main-window brand lockup: a cat head beside a two-line wordmark, with four blue letter counters and light/dark appearances.
- Restore the approved wordmark outlines and vertically center the visible cat and wordmark.
- Remove “Use Tibo estimate” from Usage forecast while keeping manual extra-reset scenarios.

## Update behavior

This Beta does not show background update prompts or install automatically. Download it manually, or enable Beta reception and check for updates manually. Stable Latest remains 2.5.1.

## 安装 / Install

Apple Silicon · macOS 13+。下载 arm64 DMG，退出旧版，将 CodexBuddy 拖入 Applications 替换。首次打开如被系统拦截，请按 README 的安装指引操作。当前发布包采用 ad hoc 签名，尚未经过 Apple 公证。

Apple Silicon · macOS 13+. Download the arm64 DMG, quit the previous app, and drag CodexBuddy into Applications to replace it. If macOS blocks the first launch, follow the installation steps in the README. This release is ad hoc signed and has not been notarized by Apple.
