# Codex Buddy v2.5.0-beta.4

## 更新内容

- 暂时移除宠物“发现”和“收藏”页的标签筛选，旧的标签选择不再影响浏览结果。搜索、来源筛选、排序和现有宠物保持可用。
- 精简重复的发布验证：完整源码一致时复用已成功的 CI 结果，最终安装包继续独立校验。

## What’s new

- Temporarily remove tag filters from Pets → Discover and Favorites. Retained tag selections no longer hide pets; search, source filters, sorting and existing pets remain available.
- Reuse successful CI verification for identical complete source trees. Final installer packages still receive independent checks.

## 安装 / Install

Apple Silicon · macOS 13+。下载 arm64 DMG，退出旧版，将 Codex Buddy.app 拖入 Applications 替换。首次打开如被系统拦截，请按 README 的安装指引操作。当前发布包采用 ad hoc 签名，尚未经过 Apple 公证。

Apple Silicon · macOS 13+. Download the arm64 DMG, quit the previous app, and drag Codex Buddy.app into Applications to replace it. If macOS blocks the first launch, follow the installation steps in the README. This release is ad hoc signed and has not been notarized by Apple.
