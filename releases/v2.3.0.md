# Codex Buddy v2.3.0

## 更新内容

- **设置窗口更方便找到**：打开设置时，Dock 会显示 Codex Buddy 图标；关闭窗口后自动隐藏，顶栏继续运行。最小化后可再次打开设置来还原窗口。
- **版本信息更集中**：在设置的“通用与更新”中查看当前版本与更新说明，减少重复信息。
- 更新多多猫应用图标。

## What’s new

- **Settings is easier to find**: Codex Buddy appears in the Dock while Settings is open. Closing the window hides the Dock icon and keeps the app running in the menu bar. Reopening Settings restores a minimized window.
- **Version information in one place**: find your installed version and release notes under General & updates in Settings.
- Updated the DuoDuoCat app icon.

## 安装 / Install

Apple Silicon · macOS 13+。下载 arm64 DMG，退出旧版，将 Codex Buddy.app 拖入 Applications 替换。首次打开如被系统拦截，请按 README 的安装指引操作。当前发布包采用 ad hoc 签名，尚未经过 Apple 公证。

Apple Silicon · macOS 13+. Download the arm64 DMG, quit the previous app, and drag Codex Buddy.app into Applications to replace it. If macOS blocks the first launch, follow the installation steps in the README. This release is ad hoc signed and has not been notarized by Apple.
