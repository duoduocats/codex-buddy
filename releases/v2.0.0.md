# Codex Buddy 2.0.0

## 更新内容

- 新增多多猫 DuoDuoCat 顶栏主题，可切换圆环与猫头、倒计时与百分比。
- 新增近 7 / 14 / 30 天每日 Token 曲线和五项使用统计，支持生成图片、系统分享、保存和复制。
- 优化中英文设置布局、顶栏比例和图表悬停提示，修复已知问题。
- 更新中英文界面展示图，安装包加入拖拽背景和双语图文首次安装指南。
- 优化原生绘制和安装包体积，并完成性能与安装回滚测试。

## What’s new

- DuoDuoCat menu bar theme, with Ring/cat and countdown/percentage choices.
- Smooth 7/14/30-day token charts, five usage statistics, and image sharing, saving and copying.
- Refined bilingual settings, menu bar proportions and chart tooltips; fixed known issues.
- Refreshed interface previews and a compact DMG with a drag-to-Applications background and illustrated Chinese/English first-install guide.
- Improved native rendering and package size, with performance and installer recovery checks.

## 安装 / Install

Apple Silicon · macOS 13+。打开 DMG，退出旧版，将 Codex Buddy.app 拖入 Applications 替换。首次打开如被拦截，请参阅安装包内的双语图文指南。当前发布包使用 ad hoc 签名，尚未经过 Apple 公证。

Apple Silicon · macOS 13+. Open the DMG, quit the previous app and drag Codex Buddy.app into Applications. If the first launch is blocked, use the illustrated bilingual guide in the DMG. This release is ad hoc signed and has not been notarized by Apple.
