# Codex Buddy v2.5.0-beta.2

## 更新内容

- 用量页新增“顶栏助手 / 用量趋势 / 用量预测”。趋势提供每日、每周、期间累计曲线、活动日历及精确用量查看；累计模式跨缺失日期连续连接，缺失记录不会补成零，部分合计保留标识。
- 预测页在同一张图展示真实额度历史、常规曲线和可选日期的额外重置情景。保留已观测的满额与历史周期；观察不足时显示预算参考，额外重置明确作为模拟，不承诺官方重置时间或到账。
- 主导航统一为“用量 / 宠物 / 消息 / 通用”。通用页重排为应用偏好、应用数据和流量统计，开关对齐；可查看缓存占用并清理目录缓存，保留个人设置、消息、收藏、已安装宠物和额度历史。
- 优化页签切换、目录索引与搜索响应，增加有界查询缓存和渐进加载；修复从系统登录项移除后重新开启的状态处理，改进窗口与 Dock 的显示、关闭和恢复。
- 宠物已安装页同时展示本机主题与当前账号可读取的 Codex 云端宠物。云端缩略图按点击加载，管理入口打开 Codex；本机卸载仍移到废纸篓。
- 增加仓库标签元数据的本地优先、按需同步与增量读取支持。标签索引尚未公开时继续使用原有目录浏览与搜索；本次不发布宠物素材或标签数据。通用页按标签、目录与预览、宠物包分类统计本应用流量。
- 修复账号切换及迟到请求可能带回旧额度、资料和重置明细的问题；预测记录按账号隔离并限制保留规模。

这是 Beta 测试版，采用“提示更新”策略。开启“接收 Beta 更新”的兼容客户端在检查到更新后显示下载提示，由用户确认安装。正式版仍为 2.4.5，关闭 Beta 接收不会自动降级。

## What’s new

- Usage now includes Menu bar assistant, Usage trends and Usage forecast. Explore daily, weekly and period-to-date curves, an activity calendar and exact token values. Cumulative curves connect known totals across missing dates without inventing zero readings; partial totals remain marked.
- Compare recorded quota history, the regular curve and an optional extra-reset scenario on one chart. Observed full-quota readings and past cycles are retained. Limited observations use a clearly labelled budget reference; extra resets are simulations, not promises of an official reset or delivery.
- Navigation is now Usage / Pets / Messages / General. General separates preferences, application data and traffic totals, with aligned switches. Clearing catalog caches preserves settings, messages, favorites, installed pets and quota history.
- Faster page switching, catalog indexing and search with bounded result caches and progressive loading. Improved login-item recovery after removal in macOS settings, plus main-window and Dock presentation and recovery.
- Installed pets includes local packages and readable Codex cloud pets for the current account. Cloud thumbnails load on click; Manage opens Codex. Local removals still use Trash.
- Added local-first, on-demand, incremental support for repository tag metadata. When no public tag index is available, normal catalog browsing and search remain usable. This release publishes neither pet artwork nor tag data. General reports app traffic for tags, catalogs/previews and pet packages.
- Prevented account switches and delayed requests from restoring stale quota, profile or reset details. Forecast history is account-isolated with bounded retention.

This Beta uses the notify update policy. Compatible clients with Receive Beta updates enabled show a download prompt after detecting it; installation requires user confirmation. Stable remains 2.4.5. Turning Beta reception off does not downgrade an installed Beta.

## 安装 / Install

Apple Silicon · macOS 13+。下载 arm64 DMG，退出旧版，将 Codex Buddy.app 拖入 Applications 替换。首次打开如被系统拦截，请按 README 的安装指引操作。当前发布包采用 ad hoc 签名，尚未经过 Apple 公证。

Apple Silicon · macOS 13+. Download the arm64 DMG, quit the previous app, and drag Codex Buddy.app into Applications to replace it. If macOS blocks the first launch, follow the installation steps in the README. This release is ad hoc signed and has not been notarized by Apple.
