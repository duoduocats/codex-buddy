# Codex Buddy v2.4.4

## 更新内容

- 新增 Beta 更新开关，默认关闭。开启后可接收 Beta 测试版；关闭时自动和手动检查都只接收正式版。
- 修复重启后的消息读取：开启接收时，通用消息和活动记录会立即检查更新，保留已缓存的内容。

## What’s new

- Added a Beta updates switch, off by default. Enable it to receive Beta releases; with it off, automatic and manual checks use stable releases only.
- Fixed message loading after restart: when receiving is enabled, reset messages and activity records check immediately while preserving cached content.

## 安装 / Install

Apple Silicon · macOS 13+。下载 arm64 DMG，退出旧版，将 Codex Buddy.app 拖入 Applications 替换。首次打开如被系统拦截，请按 README 的安装指引操作。当前发布包采用 ad hoc 签名，尚未经过 Apple 公证。

Apple Silicon · macOS 13+. Download the arm64 DMG, quit the previous app, and drag Codex Buddy.app into Applications to replace it. If macOS blocks the first launch, follow the installation steps in the README. This release is ad hoc signed and has not been notarized by Apple.
