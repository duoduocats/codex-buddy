# Codex Buddy v2.4.0

## 更新内容

- 新增 **Tibo 的 28 天挑战**：查看每天的产品改进与额度重置记录，点击日期阅读详情和原帖，活动结束后仍可在设置中回看。
- **消息通知** 支持分别选择重置提醒和活动消息，系统提醒推送相同的所选内容；关闭某类消息会同时停止接收、显示和相关提醒。
- 展开面板按消息、额度、重置明细、每日 Token 用量排列，消息可临时收起，仍有效的消息会在重新打开应用后恢复。
- 重置明细可只显示即将到期的可用重置，默认范围为未来 7 天，也可选择 1 / 3 / 14 / 30 天或查看全部。
- 当日 Token 记录尚未生成时，图表截止到昨天；已有记录且用量为 0 时正常显示，用量分享图片同步采用该规则。
- 消息时间跟随本机时区和时间格式；原帖时间无法核实时明确显示收录时间，准确公布的预计重置时间仍可显示倒计时。
- 整理设置选项并补充中英文使用说明，修复 README 顶部应用图标未居中。

## What’s new

- Added **Tibo’s 28-day challenge**: follow daily improvements and quota resets, select a date for details and original posts, and revisit records in Settings after the challenge ends.
- Choose reset reminders and activity messages independently under **Messages**. System alerts follow the same selection; disabling a type stops receiving, displaying and pushing its content.
- The panel shows messages, quota, reset expiry details and daily token usage in that order. Dismiss messages temporarily; valid messages return when the app reopens.
- Show only available resets expiring soon. The default window is 7 days, with 1 / 3 / 14 / 30-day options or a view of all records.
- If today’s token record is not available yet, the chart ends yesterday. A reported zero still appears, and shared usage images follow the same rule.
- Message times follow your Mac’s time zone and regional format. Unverified original times are clearly labelled as collection times; accurately announced reset schedules can still show countdowns.
- Updated Settings options and bilingual usage instructions, and centered the app icon at the top of both READMEs.

## 安装 / Install

Apple Silicon · macOS 13+。下载 arm64 DMG，退出旧版，将 Codex Buddy.app 拖入 Applications 替换。首次打开如被系统拦截，请按 README 的安装指引操作。当前发布包采用 ad hoc 签名，尚未经过 Apple 公证。

Apple Silicon · macOS 13+. Download the arm64 DMG, quit the previous app, and drag Codex Buddy.app into Applications to replace it. If macOS blocks the first launch, follow the installation steps in the README. This release is ad hoc signed and has not been notarized by Apple.
