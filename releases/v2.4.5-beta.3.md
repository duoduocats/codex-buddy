# Codex Buddy v2.4.5-beta.3

## 更新内容

- 消息和活动记录的正常更新检查缩短为 5 分钟，读取失败后更早重试。
- 打开活动窗口时核对最新记录，网络恢复时及时补查。
- 改善公开记录的读取可用性，主要来源不可用时尝试同一官方仓库的备用读取入口，保留已缓存记录。

## What’s new

- Message and activity checks now run every five minutes, with earlier retries after failed reads.
- Opening the activity window verifies the latest records, and network recovery triggers a follow-up check.
- Improved public-feed availability with an alternate official repository endpoint when the primary source is unavailable, while preserving saved records.

## 安装 / Install

Apple Silicon · macOS 13+。下载 arm64 DMG，退出旧版，将 Codex Buddy.app 拖入 Applications 替换。首次打开如被系统拦截，请按 README 的安装指引操作。当前发布包采用 ad hoc 签名，尚未经过 Apple 公证。

Apple Silicon · macOS 13+. Download the arm64 DMG, quit the previous app, and drag Codex Buddy.app into Applications to replace it. If macOS blocks the first launch, follow the installation steps in the README. This release is ad hoc signed and has not been notarized by Apple.
