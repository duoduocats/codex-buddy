# Codex Buddy v2.5.0-beta.3

## 更新内容

- 用量、宠物等内页改为底部导航；macOS 26 使用系统 Liquid Glass，支持拖动滑块切换，并遵循系统减少动态效果与透明度设置。通用页重新整理分组，更新拥有独立区域。
- 用量助手左侧设置与顶栏预览顶部对齐，右侧设置与主体面板垂直居中。展开重置明细或改变图表、消息显示后，布局与六条指示连线同步更新，保留模拟数据标识。
- Token 活动固定显示年度日历，用量走势独立选择近 30 天、90 天或一年。完善日历与曲线的悬停联动；日、周图表以零值呈现空白日期，累计模式延续已知累计量，均不改写原始记录。优化图表渲染和切页响应。
- 改进历史与预测曲线衔接。额外重置模拟可比较指定日期前的使用节奏和重置后的曲线；模拟不会修改真实额度，也不承诺官方重置。
- 修复宠物标签筛选，改进预览缓存与复用；已安装列表中的云端宠物在可见时自动加载缩略图，并可确认后直接删除云端宠物。系统减少动态效果开启时，预览明确显示为静态。
- 来源页面逐项显示目录数量，搜索、添加和刷新集中在同一行。移除 Petdex 内置源，保留其他 11 个来源和已有宠物；兼容旧设置、收藏及标签索引，不再获取 Petdex 目录或标签分片。
- 精修消息历史状态、开关对齐与页面留白。本次仅发布客户端，不发布宠物素材或标签数据。

本 Beta 采用“提示更新”策略。开启“接收 Beta 更新”的兼容客户端检测到新版后显示下载提示，由用户确认安装；不会静默安装。正式版仍为 2.4.5。

## What’s new

- In-page navigation moves to the bottom. On macOS 26, native Liquid Glass supports dragging the selection and respects reduced motion and transparency preferences. General is reorganized with a dedicated update area.
- Usage assistant aligns the left settings with the menu-bar preview top and centers the right settings on the main panel. Layout and all six connector lines follow changing reset details, chart and message visibility. The sample-data label remains visible.
- Token activity stays on an annual calendar while the trend chart independently offers 30 days, 90 days or one year. Improved linked hovering, rendering and page response. Daily and weekly charts render missing buckets at zero; cumulative charts carry known totals forward without rewriting source records.
- Improved continuity between recorded quota history and forecast curves. Extra-reset scenarios compare the pace before a chosen date and usage after the simulated reset; real quota is unchanged and no official reset is promised.
- Fixed pet-tag filtering and improved preview caching and reuse. Visible cloud pets load thumbnails automatically, and cloud pets can be deleted after confirmation. Reduced motion shows an explicit static preview.
- Source rows show catalog counts with search, add and refresh on one row. Removed the Petdex built-in source while preserving the other eleven sources and installed pets. Legacy settings, favorites and tag indexes remain compatible without fetching Petdex catalogs or tag shards.
- Polished message-history status, aligned switches and spacing. This release publishes the client only, without pet artwork or tag data.

This Beta uses the notify policy. Compatible clients with Receive Beta updates enabled show a download prompt after detection; installation requires confirmation and is not silent. Stable remains 2.4.5.

## 安装 / Install


Apple Silicon · macOS 13+。下载 arm64 DMG，退出旧版，将 Codex Buddy.app 拖入 Applications 替换。首次打开如被系统拦截，请按 README 的安装指引操作。当前发布包采用 ad hoc 签名，尚未经过 Apple 公证。

Apple Silicon · macOS 13+. Download the arm64 DMG, quit the previous app, and drag Codex Buddy.app into Applications to replace it. If macOS blocks the first launch, follow the installation steps in the README. This release is ad hoc signed and has not been notarized by Apple.
