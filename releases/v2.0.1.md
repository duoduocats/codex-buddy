# Codex Buddy v2.0.1

## 更新内容

- 本说明汇总本轮 2.x 重大更新的全部内容，以 v1.2.7 为更新前基线，包含 v2.0.0 新功能和 v2.0.1 安装改进。
- **多多猫 DuoDuoCat：新的顶栏模式**
- **新增多多猫模式**：圆润的耳朵与平滑猫头轮廓，搭配沿扁弧排列的四个圆点，将剩余额度与重置状态融入猫咪造型。轮廓线宽与圆点直径一致，猫头到圆点、圆点之间的五处边缘间距统一。
- 在设置中随时切换 **圆环 / 多多猫**；经典圆环设计保留。两个主题统一可见高度和上下留白，并略微缩小，让图标与其他顶栏项目更协调。
- 顶栏中央可切换 **重置倒计时 / 剩余额度百分比**。优化数字大小，百分比根据位数适配，避免贴到圆环或猫头轮廓。首次安装仍默认圆环与倒计时，升级保留已有设置。
- **展开面板：额度、曲线与统计**
- 重新布局额度区：左侧紧凑圆环、右侧剩余额度与可用重置次数，下次重置时间单独成行。圆环内加入平滑的多多猫头像，与倒计时一起垂直居中；额度轮廓保持一致粗细，灰色与前景色清晰区分。
- 新增 **近 7 / 14 / 30 天每日 Token 用量**，默认显示 14 天。平滑曲线配渐变面积、每日节点和日期 / 用量悬停提示。
- 在服务已提供每日历史时，缺失日期（包括当天）按 0 绘制，让曲线连续；整段历史不可用时显示暂无数据。
- 新增 **累计 Token、单日 Token 峰值、最长任务时长、最长连续使用天数、当前连续使用天数** 五项统计，等宽排列在同一行，适配中英文单位；接口未提供的值显示“—”。
- 优化图表左右端点的提示位置，根据文字宽度限制边界，减少长日期、长数值被裁切的问题；切换日期范围时清除旧的悬停状态。
- **用量图片分享与设置**
- 新增用量区域的 **系统分享、保存图片、复制图片**。在本机将当前日期范围的曲线与五项统计生成 PNG，支持浅色 / 深色外观，分享菜单显示用量缩略图。
- 导出图片不包含账号、登录凭据或额度面板，并移除图片中的文字和 EXIF 元数据；分享由用户主动发起。
- 优化中英文设置窗口：加入应用图标、主题和显示内容分段选择，整理区块与控件对齐，窗口高度随内容调整。
- 新增 **每日 Token 用量** 和 **用量分享按钮** 开关，默认开启。关闭每日用量后，隐藏展开面板下半部分的曲线与统计；分享按钮可单独隐藏。
- **性能、安装与文档**
- 用量统计只在面板展开且功能开启时自动获取，自动请求至少间隔五分钟并复用缓存，手动刷新可立即重新获取；配合请求去重与失败退避，统计加载失败不影响额度查询。
- 图表悬停只更新覆盖层，避免重复构建曲线和坐标轴。本轮基于 2.0.0 的本机合成测试空闲平均 CPU 约 **0.09–0.24%**；20 Hz 选择压力下约 **7.3%**，较本轮图表优化前降低约 **67%**。2.0.1 的运行源码与编译策略相同；测试方法和范围见 [质量与性能记录](https://github.com/duoduocats/codex-buddy/blob/main/docs/QUALITY.md)。
- 优化体积：使用原生组件、面向体积的编译优化及图标无损压缩，保留全部图标尺寸；不打包 CLI 或额外运行时。正式 DMG 约 **1.69 MB**，应用约 **1.90 MB**。
- 新增 Retina 拖拽安装背景及 **中英文图文首次安装指南**，说明首次打开时如何在系统设置中放行。
- 调整 DMG 窗口尺寸和上下留白，修复标题栏 / 路径栏裁切、指南选中时遮挡标题，以及图标名称溢出白色底板的问题。
- 更新中英文 README 的检索描述与界面预览，加入多多猫主题、顶栏与展开面板合并展示、设置截图和主题对比。
- 扩充主题几何、统计解析、曲线缺失日期、边缘提示、图片导出 / 分享、PDF 隐私与 DMG 布局测试，完成安装包校验、篡改拒绝、替换与回滚测试，以及源码和 Git 历史隐私审计。

## What’s new

- These notes cover the full 2.x update cycle from v1.2.7, including the features in v2.0.0 and installation improvements in v2.0.1.
- **DuoDuoCat: a new menu bar mode**
- **Introducing DuoDuoCat**: rounded ears and a smooth cat outline, with four dots on a flattened lower curve, combine remaining quota and reset status in a cat-shaped indicator. The outline matches the dot diameter, with equal edge gaps between the cat and dots and between adjacent dots.
- Switch between **Ring / DuoDuoCat** in Settings. The classic Ring design is retained. Both themes share a consistent visible height and vertical padding, with a slightly smaller size to fit alongside other menu bar items.
- Choose **reset countdown / remaining percentage** in the center. Refined number sizing adapts percentages to their digit count, keeping them clear of the outline. New installations default to Ring and countdown; upgrades preserve existing settings.
- **Expanded panel: quota, charts and statistics**
- Rearranged the quota area with a compact ring on the left, remaining quota and available resets on the right, and the next reset on its own row. A smooth DuoDuoCat head and countdown are centered together inside the ring; quota strokes remain equally thick with distinct gray contrast.
- Added a **7 / 14 / 30-day daily token chart**, defaulting to 14 days, with a smooth curve, gradient area, daily points and date/token tooltips.
- Missing dates, including today, are plotted as zero when daily history is available. Unavailable history shows an empty-data message.
- Added **lifetime tokens, peak daily tokens, longest task, longest streak and current streak**, aligned in five equal columns. Units follow the Chinese or English interface; unavailable values show “—”.
- Improved tooltip placement at both chart endpoints using the text width to keep long dates and values within bounds. Changing the date range clears the previous hover selection.
- **Usage image sharing and settings**
- Added **system sharing, Save image and Copy image**. Generate a PNG locally from the selected chart range and five statistics, in light or dark appearance. The sharing menu shows a usage-image preview.
- Exported images exclude accounts, credentials and the quota panel, and remove text and EXIF metadata. Sharing is initiated by the user.
- Refined Chinese and English Settings with the app icon, segmented theme/content controls, aligned sections and a window height that follows its content.
- Added **Daily token usage** and **Usage sharing button** switches, both on by default. Turning off daily usage hides the lower chart/statistics area; the sharing button can be hidden separately.
- **Performance, installation and documentation**
- Statistics are fetched automatically only while the panel is open and the feature is enabled. Automatic requests are at least five minutes apart and reuse cached results; manual refresh can fetch immediately. Request deduplication and failure backoff keep statistics failures from blocking quota queries.
- Chart selection updates only its overlay instead of rebuilding the curve and axes. Local synthetic tests of 2.0.0 measured **0.09–0.24% average CPU at idle** and about **7.3% under 20 Hz selection pressure**, roughly **67% less than before this cycle's chart optimization**. Runtime sources and compiler settings are unchanged in 2.0.1. See the [test methods and limits](https://github.com/duoduocats/codex-buddy/blob/main/docs/QUALITY.md).
- Reduced size with native components, size-focused compiler optimization and lossless icon compression, retaining every icon resolution. No CLI or extra runtime is bundled. The official DMG is about **1.69 MB** and the app about **1.90 MB**.
- Added a Retina drag-to-install background and an **illustrated Chinese/English first-install guide** explaining launch approval in System Settings.
- Refined DMG dimensions and spacing, fixing title/path-bar clipping, guide selection hiding the title, and filenames extending beyond the white tiles.
- Updated Chinese and English README search descriptions and previews, including DuoDuoCat, combined menu bar/panel views, Settings and theme comparisons.
- Extended geometry, statistics, missing-date, endpoint-tooltip, image export/sharing, PDF privacy and DMG layout tests. Package integrity, tamper rejection, replacement/rollback, source and reachable Git-history privacy checks passed.

## 安装 / Install

Apple Silicon · macOS 13+. Download the arm64 DMG, quit the previous app, and drag Codex Buddy.app into Applications to replace it. If macOS blocks the first launch, follow the installation steps in the README. This release is ad hoc signed and has not been notarized by Apple.
