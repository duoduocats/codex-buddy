# Codex Buddy 2.0.1

## 重大更新：安装体验改进

- 重新调整 DMG 安装窗口尺寸和上下留白，避免 Finder 标题栏、路径栏裁切背景或安装指南。
- 加高应用与 Applications 的白色底板，让图标和名称完整显示在底板内，并保留底部间距。
- 优化中英双语拖拽安装提示和图文指南入口。首次安装用户可直接查看安全放行步骤；选中指南时页面不再自动滚动遮挡标题。
- 增加 Retina 背景尺寸、DPI 和窗口布局检查，并完成安装包校验、签名、篡改拒绝及安装失败回滚测试。

## Important update: a clearer installation experience

- Refined the DMG window size and vertical spacing so Finder’s title and path bars do not clip the background or installation guide.
- Enlarged the white app and Applications tiles to contain both icons and filenames, with clear bottom padding.
- Improved the bilingual drag-to-install prompts and guide placement. First-time users can find the illustrated launch-approval steps directly; selecting the guide no longer scrolls the title out of view.
- Added checks for Retina background dimensions, DPI and window layout, with package integrity, signature, tamper rejection and installation rollback tests.

## 安装 / Install

Apple Silicon · macOS 13+。打开 DMG，将 Codex Buddy.app 拖入 Applications。首次打开如被拦截，请参阅安装包内的中英文图文指南。当前发布包使用 ad hoc 签名，尚未经过 Apple 公证。

Apple Silicon · macOS 13+. Open the DMG and drag Codex Buddy.app into Applications. If the first launch is blocked, use the illustrated English and Chinese guide in the DMG. This release is ad hoc signed and has not been notarized by Apple.
