# CodexBuddy v2.5.2

## 更新内容

- 改进用量页和宠物页的底部导航。静止时图标清晰。按下和拖动时，玻璃指示器在宽度和高度上同时放大，带有图标倒影。拖动期间玻璃保持固定尺寸，松手后恢复普通选中态。
- 点击菜单栏用量图标只开关用量浮层，主窗口已关闭或最小化时保持原状态。
- 应用统一显示为 CodexBuddy，主窗口使用新的猫头和字标。用量预测保留手动额外重置模拟，移除 Tibo 估计入口。

## 更新方式

客户端检测到该正式版后会提示下载。安装由用户确认。

## What’s new

- Refine bottom navigation in Usage and Pets. Icons stay crisp at rest. Pressing and dragging expands the glass indicator in both dimensions and shows the icon reflection. The indicator holds its size during the drag and returns to a flat selection on release.
- Clicking the menu bar usage icon toggles its panel and preserves the state of closed or minimized main windows.
- The app now displays as CodexBuddy and uses the new cat and wordmark in the main window. Usage Forecast keeps manual extra-reset scenarios and removes the Tibo estimate option.

## Update behavior

Compatible clients show a download prompt after detecting this stable release. Installation requires user confirmation.

## 安装 / Install

Apple Silicon · macOS 13+。下载 arm64 DMG，退出旧版，将 CodexBuddy 拖入 Applications 替换。首次打开如被系统拦截，请按 README 的安装指引操作。当前发布包采用 ad hoc 签名，尚未经过 Apple 公证。

Apple Silicon · macOS 13+. Download the arm64 DMG, quit the previous app, and drag CodexBuddy into Applications to replace it. If macOS blocks the first launch, follow the installation steps in the README. This release is ad hoc signed and has not been notarized by Apple.
