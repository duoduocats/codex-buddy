# Codex Buddy v2.5.1

## 更新内容

- 优化宠物列表快速滚动时的图片加载：下载与图片解码分开并行，离屏任务及时取消。
- 合并重复图片请求，直接显示已缓存的缩略图；先出图再写入和整理缓存，减少等待。
- 保留现有宠物、来源和设置。首次加载未缓存图片的速度仍取决于网络。

## What’s new

- Improve image loading during fast scrolling in the pet list with separate bounded download and decoding queues and offscreen cancellation.
- Coalesce duplicate image requests and display cached thumbnails immediately; show artwork before persisting and trimming the cache.
- Preserve existing pets, sources, and settings. First-time loads of uncached images still depend on network speed.

## 安装 / Install

Apple Silicon · macOS 13+。下载 arm64 DMG，退出旧版，将 Codex Buddy.app 拖入 Applications 替换。首次打开如被系统拦截，请按 README 的安装指引操作。当前发布包采用 ad hoc 签名，尚未经过 Apple 公证。

Apple Silicon · macOS 13+. Download the arm64 DMG, quit the previous app, and drag Codex Buddy.app into Applications to replace it. If macOS blocks the first launch, follow the installation steps in the README. This release is ad hoc signed and has not been notarized by Apple.
