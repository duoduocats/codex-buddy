# Codex Buddy v2.5.0-beta.1

## 更新内容

- 全新主面板：用量概览、宠物、消息和通用集中在同一窗口。顶栏与展开面板使用整体预览，调整时同步显示效果，并明确标注模拟数据。
- 集成 Codex 社区宠物商店：浏览十二个公开来源，搜索宠物与作者，按名称或来源热度排序，收藏喜欢的主题，并管理本机已安装宠物及自定义来源。
- 完整动作预览：一次点击切换待机、走动、挥手、跳跃、工作等动作；v2 主题支持环视，并可暂停或继续播放。
- 确认后安装、覆盖或卸载宠物。覆盖安装保留恢复副本，卸载移到废纸篓；安装后仍需在 Codex 的虚拟宠物设置中刷新并选择使用。独立 Codex Pets 应用继续保留，两者收藏、来源设置及缓存各自保存。
- 消息页可滚动查看最近公告和已结束展示的历史记录，类型与时间排版更清晰。悬浮台历打开 Tibo 的 28 天挑战，结束后可继续回看历史活动。
- 优化时间与百分比按钮的点击响应、预览更新速度、窗口默认高度和导航定位。展开重置明细时拥有更充足的展示空间，设置开关统一对齐。
- 宠物页按需加载；离开页面、关闭窗口或最小化后停止浏览请求和动画。更新与退出会等待已确认的宠物安装、卸载操作完成。

这是 Beta 测试版。已有用户可在“通用”开启“接收 Beta 更新”后检查；安装 Beta 后关闭该选项不会自动降级。原有用量与消息设置会保留。

## What’s new

- A redesigned main window brings Usage overview, Pets, Messages and General together. A combined menu-bar and panel preview updates with your choices and clearly labels its sample data.
- Browse Codex community pets from twelve public sources, search pets or authors, sort by name or source popularity, save favorites, and manage installed pets and custom catalogs.
- Preview every animation with one-click controls, including idle, walking, waving, jumping and working. Supported v2 themes also include look-around, with pause and resume.
- Confirm each pet installation, replacement or removal. Replacements keep recovery copies and removals go to Trash. Choose the installed pet manually in Codex settings. The standalone Codex Pets app remains available; favorites, source settings and caches stay separate.
- Scroll recent and past announcements in Messages with clearer type and timestamp layout. Its floating calendar opens Tibo’s 28-day challenge and keeps past activity available afterward.
- Improved time/percentage button responsiveness, preview updates, default window height and navigation positioning. Reset details have more room, and switches use aligned columns.
- Pet browsing loads on demand and stops requests and animations when you leave, close or minimize. Updates and quitting wait for confirmed pet installation or removal to finish.

This is a Beta release. Existing users can enable Receive Beta updates in General and check for updates. Disabling Beta after installation does not downgrade the app. Existing quota and message settings are preserved.

## 安装 / Install

Apple Silicon · macOS 13+。下载 arm64 DMG，退出旧版，将 Codex Buddy.app 拖入 Applications 替换。首次打开如被系统拦截，请按 README 的安装指引操作。当前发布包采用 ad hoc 签名，尚未经过 Apple 公证。

Apple Silicon · macOS 13+. Download the arm64 DMG, quit the previous app, and drag Codex Buddy.app into Applications to replace it. If macOS blocks the first launch, follow the installation steps in the README. This release is ad hoc signed and has not been notarized by Apple.
