# Codex Buddy 2.1.0

## 更新内容

- 新增展开面板消息，可查看额度重置预告等消息。
- 在设置中开启“消息提醒”并允许 macOS 通知，即可接收新消息的系统通知。
- 有截止时间的消息可显示倒计时；点击 × 可暂时收起消息。
- 点击设置旁的圆形下载按钮更新。在设置中查看更新说明和下载状态，下载失败时可重试。

## What’s new

- Added messages in the expanded panel, such as announcements about upcoming quota resets.
- Turn on Message reminders in Settings and allow macOS notifications to receive system notifications for new messages.
- Messages with a deadline can show a countdown. Click × to temporarily hide a message.
- Use the circular download button beside Settings to update. View release notes and download status in Settings, and retry if the download fails.

## 安装 / Install

Apple Silicon · macOS 13+。打开 arm64 DMG，退出旧版，将 Codex Buddy.app 拖入 Applications 替换。首次安装安全放行步骤见安装包内的中英文图文指南。当前构建为 ad hoc 签名，尚未经过 Apple 公证。

Apple Silicon · macOS 13+. Open the arm64 DMG, quit the previous app, and drag Codex Buddy.app into Applications. First-launch approval steps are illustrated in the Chinese/English guide inside the DMG. This build is ad hoc signed and not Apple-notarized.
