# Codex Buddy 2.1.0

## 更新内容

- 新增轻量消息提醒。全球重置等消息显示在展开面板的一行内，可带倒计时；× 仅本次运行隐藏，重启后有效消息恢复，已到截止时间或过期的消息不再显示。
- 设置只增加一个“消息提醒”开关。主动开启并允许 macOS 通知后，新消息以系统通知提醒；不安排提前或到点提醒，不单独设全球重置模块。
- 更新入口改为设置按钮旁的圆形下载按钮，不再自动弹窗。更新说明与下载状态集中在设置；下载或校验失败保留当前版本并支持重试。
- 消息与应用版本独立，从 GitHub 公共文件读取，支持缓存、启动 / 唤醒检查和失败退避。同一消息的同一修订只通知一次，请求不附带账号凭据、Cookie、设备标识或版本统计参数。
- 提供维护者使用的 GitHub 各版本 DMG 下载次数脚本，应用不增加统计上报；下载次数不代表安装版本分布或活跃用户数量。

## What’s new

- Added lightweight messages in one row of the expanded panel. Time-sensitive messages can include a countdown. × hides a message until restart; expired messages and elapsed deadlines stay hidden.
- Settings adds one Message reminders switch. Enable it and allow macOS notifications to receive new messages. There are no early or deadline alerts, and no separate global-reset module.
- Updates use a circular download button beside Settings without automatic dialogs. Release notes and download status stay in Settings. Download or verification failure preserves the current app and allows retry.
- Messages use an independent public GitHub file, with caching, startup/wake checks and failure backoff. Each active revision notifies once. Requests carry no account credentials, cookies, device identifiers or version-measurement parameters.
- Added a maintainer-only script for public GitHub DMG download counts. No app telemetry is added; downloads do not measure installed versions or active users.

## 使用 / Usage

展开面板自动显示有效消息。若需要系统通知，在设置开启“消息提醒”并授权。消息源只放经确认的公共信息，不上传私人截图；全球重置时间需核实后才发布。详见 [消息发布说明](https://github.com/duoduocats/codex-buddy/blob/main/announcements/README.md)。

Valid messages appear in the expanded panel. For system notifications, enable Message reminders in Settings and grant permission. The feed contains verified public information, without private screenshots; a global-reset time must be confirmed before publication. See the [message guide](https://github.com/duoduocats/codex-buddy/blob/main/announcements/README.md).

## 安装 / Install

Apple Silicon · macOS 13+。打开 arm64 DMG，退出旧版，将 Codex Buddy.app 拖入 Applications 替换。首次安装安全放行步骤见安装包内的中英文图文指南。当前构建为 ad hoc 签名，尚未经过 Apple 公证。

Apple Silicon · macOS 13+. Open the arm64 DMG, quit the previous app, and drag Codex Buddy.app into Applications. First-launch approval steps are illustrated in the Chinese/English guide inside the DMG. This build is ad hoc signed and not Apple-notarized.
