# Codex Buddy v2.5.0

## 更新内容

- 全新主面板：用量、宠物、消息、通用四个入口；用量助手提供带模拟数据标识的即时预览，开关、布局和指示连线同步变化。
- 用量趋势加入独立年度 Token 日历、日／周／累计曲线与悬停联动。用量预测对比已记录历史、常规曲线和额外重置模拟；模拟不修改真实额度，也不承诺官方重置。
- 集成宠物主题商店：11 个社区来源、搜索、来源筛选、排序、本机收藏、动作和环视预览，以及安装、卸载和恢复副本。可见云端缩略图自动加载，云端删除需确认。标签筛选暂时移除，已有数据保留；宠物素材不随应用打包。
- 消息中心集中展示近期公告，悬浮台历打开 Tibo 的 28 天挑战，活动结束后保留历史记录。
- 通用页将偏好、更新、应用数据和流量统计独立分区。改进启动项管理、Dock 图标显示、切页与预览缓存；缓存清理保留额度历史和个人数据。
- macOS 26 使用支持拖动切换的系统 Liquid Glass 底部导航；旧系统使用兼容样式，并遵循系统减少动态效果与透明度设置。

本版将已验收的 2.5 Beta4 客户端功能转为正式版，采用“提示更新”策略。兼容客户端检测到新版后提示下载，由用户确认安装；无需开启 Beta 接收。

## What’s new

- A redesigned main window with Usage, Pets, Messages and General. Usage assistant provides a clearly labelled live sample preview, synchronized controls, layout and connector lines.
- Usage trends adds an independent annual token calendar, daily/weekly/cumulative charts and linked hovering. Forecast compares recorded history, a regular curve and hypothetical extra resets without altering quota or promising official resets.
- Integrated pet store with eleven community sources, search, source filtering, sorting, local favorites, action/look previews and local installation/removal with recovery copies. Visible cloud thumbnails load automatically; cloud deletion requires confirmation. Tag filters are temporarily removed, existing data is retained, and artwork is not bundled.
- Messages collects recent notices and opens Tibo's 28-day challenge through a floating calendar, retaining past activity records.
- General separates preferences, updates, app data and traffic statistics. Improved login-item management, Dock presentation, page response and preview caching; cache cleanup preserves quota history and personal data.
- On macOS 26, native Liquid Glass bottom navigation supports dragging. Older systems use a compatible style, respecting reduced motion and transparency.

This stable release promotes the validated 2.5 Beta4 client functionality. Compatible clients show an update prompt after detection, and installation requires confirmation. Beta reception is not required.

## 安装 / Install

Apple Silicon · macOS 13+。下载 arm64 DMG，退出旧版，将 Codex Buddy.app 拖入 Applications 替换。首次打开如被系统拦截，请按 README 的安装指引操作。当前发布包采用 ad hoc 签名，尚未经过 Apple 公证。

Apple Silicon · macOS 13+. Download the arm64 DMG, quit the previous app, and drag Codex Buddy.app into Applications to replace it. If macOS blocks the first launch, follow the installation steps in the README. This release is ad hoc signed and has not been notarized by Apple.
