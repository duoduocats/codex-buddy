# Codex Buddy v2.4.3

## 更新内容

- 修复下拉面板顶部内容被裁切、底部留白及滚动后收起位置异常的问题。
- 消息过期或关闭消息、切换用量图表时，面板会及时恢复正确高度。

## What’s new

- Fixed clipped content, excess blank space and misplaced content after scrolling or collapsing the panel.
- The panel now follows its content when messages expire or are disabled, and when the usage chart is shown or hidden.

## 安装 / Install

Apple Silicon · macOS 13+。下载 arm64 DMG，退出旧版，将 Codex Buddy.app 拖入 Applications 替换。首次打开如被系统拦截，请按 README 的安装指引操作。当前发布包采用 ad hoc 签名，尚未经过 Apple 公证。

Apple Silicon · macOS 13+. Download the arm64 DMG, quit the previous app, and drag Codex Buddy.app into Applications to replace it. If macOS blocks the first launch, follow the installation steps in the README. This release is ad hoc signed and has not been notarized by Apple.
