# Codex Buddy v2.4.5-beta.2

## 更新内容

- 消息展开、收起和关闭更平滑，面板高度同步调整，并遵循系统减少动态效果设置。
- 更新检查失败后自动重试，网络恢复或 Mac 唤醒时及时补查；设置显示最近成功检查及下次重试时间。
- 改进正式版与 Beta 的更新选择，安装前再次核对版本，避免安装已撤回或被修改的更新。
- 新版启动异常时恢复旧版，避免自动反复安装同一失败版本，保留手动重试。
- 本测试版仅向开启“接收 Beta 更新”的用户提供。

## What’s new

- Smoother message expansion, collapse, and dismissal, with synchronized panel resizing and support for Reduce Motion.
- Failed update checks retry automatically, with follow-up checks after network recovery or Mac wake. Settings show the last successful check and next retry.
- Improved stable and Beta release selection, with another version check before installation to avoid withdrawn or changed updates.
- Restore the previous app when the replacement fails to start, avoid repeated automatic installation of the failed version, and keep manual retry available.
- This Beta is offered only to users who enable Receive Beta updates.

## 安装 / Install

Apple Silicon · macOS 13+。下载 arm64 DMG，退出旧版，将 Codex Buddy.app 拖入 Applications 替换。首次打开如被系统拦截，请按 README 的安装指引操作。当前发布包采用 ad hoc 签名，尚未经过 Apple 公证。

Apple Silicon · macOS 13+. Download the arm64 DMG, quit the previous app, and drag Codex Buddy.app into Applications to replace it. If macOS blocks the first launch, follow the installation steps in the README. This release is ad hoc signed and has not been notarized by Apple.
