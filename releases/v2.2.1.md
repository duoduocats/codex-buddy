# Codex Buddy 2.2.1

## 更新内容

- **多多猫图标新增玻璃质感**：在支持的 macOS 上呈现系统高光、阴影与立体效果。
- **深色图标保留品牌蓝色**：蓝色背景搭配黑色猫头和四个点，支持系统图标外观切换。
- **修复图标更新显示**：改善更新后 Dock、启动台及其他位置仍显示旧图标的问题。

## What’s new

- **A glass look for DuoDuoCat**: system highlights, shadows and depth on supported macOS versions.
- **Blue stays in Dark appearance**: a blue background with a black cat and four dots, with system icon appearance support.
- **More reliable icon updates**: fixes cases where the Dock, app launcher or other locations continued to show the old icon after updating.

## 安装 / Install

Apple Silicon · macOS 13+。下载 arm64 DMG，退出旧版，将 Codex Buddy.app 拖入 Applications 替换。首次安装安全放行步骤见安装包内的中英文图文指南。当前构建尚未经过 Apple 公证。

Apple Silicon · macOS 13+. Download the arm64 DMG, quit the previous app, and drag Codex Buddy.app into Applications. The DMG includes an illustrated Chinese/English first-install guide. This build is not Apple-notarized.
