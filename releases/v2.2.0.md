# Codex Buddy 2.2.0

## 更新内容

- **多多猫成为默认主题**：首次安装即可使用多多猫，仍可切换经典圆环；升级保留已有选择。
- **查看重置到期明细**：可查看全部可用重置的到期时间，也可只显示最近到期的一组。
- **额度与用量更易读**：剩余额度、下次重置、到期明细和每日 Token 统计更清晰，设置选项也更容易查找。
- **消息由你决定**：自主选择是否接收消息，接收后可单独开启系统通知；关闭接收消息后不再推送。
- **消息时间更明确**：显示具体日期、时间与时区，跟随 Mac 的时区和时间格式；有预计时间的消息可查看倒计时。
- **分享图片新增猫头标识**：用量图片带上多多猫猫头，可通过系统分享，也可保存或复制。

## What’s new

- **DuoDuoCat is now the default theme** for new installations. Ring remains available, and upgrades keep your choice.
- **See when resets expire**: view all available reset expirations or only the next group to expire.
- **Read quota and usage at a glance**: clearer quota, reset and daily Token information, with easier-to-find settings.
- **Choose how to receive messages**: receive messages in the panel and optionally enable system notifications. Turning off messages also stops notifications.
- **Clearer message times**: dates, times and time zones follow your Mac’s settings. Messages with an expected time include a countdown.
- **A cat-head mark on shared usage images**: share through macOS, save an image or copy it.

## 安装 / Install

Apple Silicon · macOS 13+。下载 arm64 DMG，退出旧版，将 Codex Buddy.app 拖入 Applications 替换。首次安装安全放行步骤见安装包内的中英文图文指南。当前构建尚未经过 Apple 公证。

Apple Silicon · macOS 13+. Download the arm64 DMG, quit the previous app, and drag Codex Buddy.app into Applications. The DMG includes an illustrated Chinese/English first-install guide. This build is not Apple-notarized.
