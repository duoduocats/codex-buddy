# Codex Buddy 1.2.6

## 更新内容 / Changes

- 调整顶栏圆环大小、线宽与灰色亮度，统一四个圆点的大小和间距。
- 加深展开面板的灰色圆弧与圆点，改善浅色背景下的辨识度。
- Codex 图标和倒计时作为一组在圆环内垂直居中。
- 更新中英文 README 界面截图。
- Refined menu bar ring size, stroke weight and gray contrast; made reset dots equal in size and evenly spaced.
- Improved detail-ring and reset-dot contrast on light backgrounds.
- Vertically centered the Codex icon and countdown together inside the ring.
- Updated Chinese and English README screenshots.

## 安装 / Install

Apple Silicon / macOS 13+. 下载 DMG，将 Codex Buddy.app 拖入 Applications 替换，或在应用设置中检查更新。当前构建为 ad hoc 签名，尚未公证；首次打开方式见 README。

Download the DMG and replace the app in Applications, or check for updates in the app settings. This build is ad hoc signed and not notarized; see the README for first-launch instructions.
