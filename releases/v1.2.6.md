# Codex Buddy v1.2.6

## 更新内容

- 调整顶栏圆环大小、线宽与灰色亮度，统一四个圆点的大小和间距。
- 加深展开面板的灰色圆弧与圆点，改善浅色背景下的辨识度。
- Codex 图标和倒计时作为一组在圆环内垂直居中。
- 更新中英文 README 界面截图。

## What’s new

- Refined menu bar ring size, stroke weight and gray contrast; made reset dots equal in size and evenly spaced.
- Improved detail-ring and reset-dot contrast on light backgrounds.
- Vertically centered the Codex icon and countdown together inside the ring.
- Updated Chinese and English README screenshots.

## 安装 / Install

Apple Silicon · macOS 13+。下载 arm64 DMG，退出旧版，将 Codex Buddy.app 拖入 Applications 替换。首次打开如被系统拦截，请按 README 的安装指引操作。当前发布包采用 ad hoc 签名，尚未经过 Apple 公证。

Apple Silicon · macOS 13+. Download the arm64 DMG, quit the previous app, and drag Codex Buddy.app into Applications to replace it. If macOS blocks the first launch, follow the installation steps in the README. This release is ad hoc signed and has not been notarized by Apple.
