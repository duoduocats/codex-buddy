# Codex Buddy — macOS ChatGPT / Codex 额度监控

简体中文 · [English](README.en.md) · [下载正式版](https://github.com/duoduocats/codex-buddy/releases/latest) · [Beta 使用说明](docs/BETA.md)

在 Mac 菜单栏查看 **ChatGPT / Codex 剩余额度、重置倒计时和每日 Token 用量**。点击顶栏图标，即可展开额度详情与用量曲线。

原生 macOS 小工具，支持 **Apple Silicon · macOS 13+**。使用本机已有的 ChatGPT / Codex 登录状态，无需另填 API Key。

本页介绍当前[正式版 2.5.0](https://github.com/duoduocats/codex-buddy/releases/tag/v2.5.0)，包含新主面板、即时预览、用量趋势与预测，以及集成宠物商店。

## 多多猫 DuoDuoCat

选择 **多多猫** 或经典圆环。在一个小图标里查看额度、重置倒计时和可用重置次数，可在设置中随时切换主题。

## 主要功能

- **额度一眼可见**：圆环或多多猫显示剩余额度，中央可选重置倒计时或百分比；四个圆点表示可用重置次数。
- **每日 Token 用量**：查看近 7 / 14 / 30 天的每日用量。当日尚未生成记录时曲线截止到昨天；真实 0 用量仍会显示。
- **五项使用统计**：累计 Token、单日峰值、最长任务、最长连续和当前连续使用天数。
- **用量趋势与预测**：年度 Token 活动、日／周／累计曲线和悬停联动；根据已记录的额度历史比较常规使用与额外重置模拟。
- **宠物主题商店**：浏览 11 个社区来源，搜索和收藏主题，预览动作，安装到本机并管理已安装宠物。
- **用量图片分享**：将所选日期范围的曲线和统计生成图片，通过系统菜单分享、保存或复制。
- **消息与重置提醒**：在展开面板接收公告；有准确预计重置时间时显示倒计时，可选择开启系统提醒。
- **消息中心与特别活动**：滚动查看公告，通过悬浮台历打开 Tibo 的 28 天挑战；活动结束后保留历史记录。
- **应用内更新**：在设置中查看当前版本与更新说明，直接下载并安装新版本。
- **按需显示**：可隐藏每日用量区域或分享按钮，也可开启开机启动。
- **中英文界面**：跟随 macOS 首选语言，重置日期和时间遵循系统时区及 12 / 24 小时设置。

在 **用量 → 用量助手 → 展开面板** 中开启 **重置明细**，可查看可用重置的到期时间。展示范围可选 **全部** 或 **最近到期**；最近到期默认显示未来 7 天内的记录，可选 1 / 3 / 7 / 14 / 30 天，相同时间到期的重置合并显示。

## 主面板与用量

主窗口分为 **用量、宠物、消息、通用**。打开主窗口或活动窗口时，Dock 显示应用图标；关闭所有窗口后，应用继续在顶栏运行。

**用量助手** 围绕中央的顶栏和展开面板样例调整显示选项，修改设置时同步显示预览。样例标有 **模拟数据预览**；实际顶栏和展开面板继续显示当前账号的真实用量。macOS 26 使用支持拖动切换的系统 Liquid Glass 底部导航，旧系统使用兼容样式，并遵循系统减少动态效果与透明度设置。

**用量趋势** 的年度 Token 日历与下方曲线范围独立，曲线可选近 30 天、90 天或一年。悬停日历或曲线可联动定位日期，查看精确 Token 数。日／周曲线以零值呈现空白日期，累计模式延续已知累计量；原始缺失记录不改写，部分合计显示“≥”。

**用量预测** 展示已记录的额度历史和常规曲线。开启 **额外重置（模拟）** 并选择日期后，可在同图比较假设情景。样本不足时显示预算参考；模拟不改变真实额度，也不代表官方重置承诺。过去未记录的数据无法补回。

## 宠物主题

在 **宠物** 中切换 **发现、收藏、已安装、来源**，浏览社区主题、按关键词和来源筛选、按名称或热度排序，并保存本机收藏。支持动作预览与 v2 主题的环视预览。标签筛选已暂时移除，已有标签说明与本地数据保留。

选择 **安装到本机**，核对作者、授权和目标目录后确认。安装后在 Codex 设置中进入 **虚拟宠物**，刷新并选择使用。已安装主题可移到废纸篓；覆盖安装保留恢复副本。

已安装列表也展示当前账号可读取的 Codex 云端宠物，可见缩略图自动加载；删除云端宠物需确认。内置 11 个来源，Petdex 不再作为内置源提供，已有宠物保留。社区素材按需加载，不包含在应用包中。

Buddy 与独立 Codex Pets 的收藏、来源和缓存分别保存，两边可识别同一个 Codex 宠物目录。

**通用** 将应用偏好、更新、应用数据和流量统计分区展示，可管理开机启动、系统提醒和 Beta 接收。清理缓存保留额度历史与个人数据。

## 消息与更新

展开面板可查看额度重置预告等消息，时间跟随本机时区及日期格式。官方提供准确预计重置时间时，可查看预计时间和倒计时；其他消息显示发布时间，原帖时间无法核实时则明确显示收录时间。消息过期后自动隐藏。点击 **×** 可临时收起；重新打开应用后，仍有效的消息会再次显示。

**消息** 页保留最近公告列表，可滚动查看；结束展示的内容以历史消息标记。

在 **用量 → 用量助手 → 展开面板** 中，**消息通知** 控制是否接收并显示消息，可分别选择 **重置提醒** 和 **活动消息**；**通用** 中的 **系统提醒** 独立控制向 macOS 通知中心推送相同的所选内容。关闭消息通知后，不再接收或推送消息，活动入口同时隐藏，已打开的活动窗口也会关闭。

下拉面板依次显示消息、额度、重置明细和每日 Token 用量。点击顶部活动消息中的 **查看活动**，或在 **消息** 页点击 **特别活动** 台历，可查看 **Tibo 的 28 天挑战** 完整进度；挑战日期按美西时间计算，消息时间按本机时区显示。活动结束后，相关入口从展开面板移除，**消息** 页的 **历史活动** 入口保留记录。系统提醒按照消息类型选择推送，关闭推送仍可在面板查看消息。

“消息通知”下的 **重置提醒** 和 **活动消息** 可分别关闭。关闭任一消息类型，会停止获取、隐藏该类消息并停止相关推送；关闭活动消息还会关闭活动窗口。总开关关闭时，两个子开关不可用，但会保留各自的选择。

活动期间，消息与活动记录每 5 分钟检查更新。打开活动窗口或网络恢复时会及时补查；读取失败会自动重试，并保留已有记录。

<img src="docs/images/challenge-zh.png" width="720" alt="Tibo 的 28 天挑战：日历进度、每日改进详情和原帖入口" />

在 **通用 → 更新** 中点击 **检查更新**，可查看新版本和更新说明。有可用更新时，可在该区域或展开面板中的 **下载更新** 入口完成应用内升级。本正式版采用提示更新策略，检测后提示下载，由用户确认安装。

Beta 更新开关默认关闭，位于 **通用 → 更新** 中。开启后可接收 Beta 测试版更新；关闭时，自动和手动检查都只接收正式版。关闭 Beta 后不会自动降级；已安装较新测试版时，会等待更高版本的正式版。

设置中会显示最近成功检查更新的时间。暂时断网会自动重试；更新失败时保留可用版本。

## 下载与首次安装

1. 从 [GitHub Releases](https://github.com/duoduocats/codex-buddy/releases/latest) 下载 **arm64 DMG** 并打开。
2. 将 **Codex Buddy.app** 拖入右侧的 **Applications（应用程序）**。
3. 从应用程序目录打开 Codex Buddy，在菜单栏查看额度。先确保本机 ChatGPT / Codex 已登录。

安装包内提供拖拽安装背景和 **[中英文图文安装指南](docs/install/Installation-Guide.pdf)**，首次安装可直接查看。

### macOS 提示无法验证开发者时

当前发布包使用 ad hoc 签名，尚未经过 Apple 公证。确认安装包来自本仓库后：

1. 尝试打开应用一次，关闭拦截提示。
2. 打开 **系统设置 → 隐私与安全性**，向下找到 Codex Buddy 的提示，点击 **仍要打开**。
3. 按系统提示完成确认，再点击 **打开**。

该应用会被保存为安全性例外。以上适用于开发者身份或公证提示；若系统报告恶意软件或文件损坏，请停止安装并重新检查下载来源。步骤依据 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。

## 常见问题

### 能查看哪些 ChatGPT / Codex 额度？

显示当前登录账号的 Codex 使用限额、剩余额度、下次重置时间及可用重置次数；若有多个额度窗口，可在展开面板中切换。暂不可用的数据显示“—”。Token 用量与额度消耗百分比是不同指标。

### 登录后仍然没有数据？

在本机 ChatGPT / Codex 中确认登录状态，再点击面板的刷新按钮。若仍无数据，请检查网络并尝试更新到最新版。

### 为什么没有收到消息通知？

先在展开面板设置开启消息通知并选择要接收的类型，开启系统提醒，然后检查 **系统设置 → 通知 → Codex Buddy**。专注模式、网络不可用、应用退出或设备休眠可能影响通知。

### 支持 Intel Mac 吗？

当前发布包仅支持 Apple Silicon（arm64），最低系统为 macOS 13。

### 如何切换界面语言？

支持简体中文和英文，默认跟随 macOS 首选语言。也可在系统设置中单独设置应用语言，重新打开应用后生效。
